# Portfolio Alif

Website portfolio modern menggunakan React dan Vite.

## Features

- Modern UI
- Responsive Design
- React Components
- Smooth Navigation
- Dark Theme

## Technology

- React JS
- Vite
- CSS3
- JavaScript

## Run Project

Install dependency:

```bash
npm install
````

Jalankan project:

```bash
npm run dev
```

Build project:

```bash
npm run build
```
